## Qué cambió en REV02.1

- Se recompuso todo el texto a partir del PDF original V4.06, evitando el daño de tildes y eñes de la primera importación.
- Los **16 arranques** restaurados llevan banderola, título, imagen y capitular.
- Se mantuvieron las seis ilustraciones nuevas: capítulos **7, 9, 11, 12, 13 y 14**.
- El índice se recalculó para los comienzos de página 15, 17, 27, 33, 40, 49, 57, 66, 79, 85, 98, 106, 117, 123, 133 y 138.
- No se añadió prosa durante la recomposición; la cifra de páginas aumentó por tipografía, proporciones de imagen y espaciado.
- El trabajo anterior reporta 974/974 párrafos narrativos íntegros detectados y 16/16 aperturas cotejadas; no se ha repetido una auditoría editorial manual integral para esta sincronización GitHub.
